# 🔬 Portfólio — Dr. Walter Paixão

Site de portfólio profissional desenvolvido para o **Dr. Walter Paixão**, Biomédico e Doutor em Nanociências pela Universidade Franciscana (UFN).

## 🌐 Demo

> Faça o deploy via GitHub Pages para disponibilizar o site online.

## 📋 Sobre o Projeto

Portfolio pessoal com foco acadêmico e científico, apresentando:

- Áreas de expertise (Biotecnologia, Bioinformática, Nanomateriais)
- Formação acadêmica (Graduação, Mestrado, Doutorado)
- Publicações científicas e trabalhos apresentados
- Habilidades técnicas e ferramentas utilizadas
- Informações de contato e Currículo Lattes

## 🛠️ Tecnologias

- HTML5 + CSS3 puro (sem frameworks)
- Google Fonts: Playfair Display, DM Mono, DM Sans
- Design responsivo (mobile-first)
- Animações CSS nativas
